# 07 · UX

## 1. Principles

| Principle | In practice |
|---|---|
| **Instant** | Everything renders from local data. Taps update the screen before the server answers. No loading spinners on main screens. |
| **One step to log** | One tap in the app, one sentence to Siri, or one button in the notification. |
| **Undo, don't confirm** | Actions happen immediately with an *Undo* option. Confirmation dialogs only for destructive actions (delete habit, delete account). |
| **Forgiving** | Skips, pauses, logging past days, and a day that ends at 04:00. Streaks reflect real effort, not bad luck. |
| **Calm** | Reminders only when still needed; quiet hours; celebrations without guilt. |
| **Show only what's needed** | Short forms with advanced options folded away; detail on demand. |
| **For everyone** | Spanish and English, WCAG 2.2 AA, phone and desktop. |

## 2. UI/UX patterns (brief NFR 4)

| Pattern | Where |
|---|---|
| Optimistic UI + Undo toast | Every check-in and edit |
| Offline-first with a sync status indicator | App header |
| Gestures with visible alternatives: swipe right = done, swipe left = skip, long press = more options; the same actions are in the "…" menu | Today rows |
| Short form with a live summary ("Mon, Tue, Thu, Fri at 07:00 · reminder at 06:55") | Habit editor |
| Smart defaults: templates, detected language and timezone, suggested routine times | Onboarding, editor |
| Focused step-by-step flow | Routine mode |
| Small animations and celebrations, turned off by "reduce motion" | Check-ins, milestones, perfect day |
| Empty states with one clear action | Every list |
| Command palette (⌘K / Ctrl K) and keyboard shortcuts | Desktop |
| View Transitions between list and detail, where supported | Habits, stats |
| Bottom sheets on phone; dialogs and side panels on desktop | Menus, editors |

## 3. Navigation and layout

- **Phone (< 640 px):** bottom tab bar with **Today · Habits · Stats · Settings**. Routine mode and the habit editor open full screen.
- **Tablet (640–1023 px):** the same tabs. Lists and details side by side when in landscape.
- **Desktop (≥ 1024 px):** left sidebar. Today in two columns (routines | day summary and week). Habit details open in a side panel.

| Route | Screen |
|---|---|
| `/today` | Today (start screen) |
| `/routine/[id]` | Routine mode |
| `/habits`, `/habits/new`, `/habits/[id]`, `/habits/[id]/edit` | List, editor, detail |
| `/stats` | Statistics |
| `/review/[week]` | Weekly review |
| `/settings/*` | Profile, notifications, routines, categories, integrations, data |
| `/login`, `/onboarding` | Sign-in and first-run setup |

- **Header:** day (with ‹ › to move between days in the edit window), score ring, done/total, best active streak, sync status.
- **Row actions:** tap = done / +step · swipe right = done · swipe left = skip (a bottom sheet asks for a reason and shows skips left this month) · long press or "…" = value, note, skip, edit, pause.
- **States:** ✅ done · ◐ partial · ○ pending · ✕ missed (past days) · ⏭ skipped · 🩺 "Verified by Health" badge.
- **Undo toast** at the bottom for 5 s after each action, read by screen readers.
- **Rest day:** an illustration and the weekly habits, if any.
- **Setup checklist** at the top until finished or dismissed (`FR-TOD-7`).

### 4.2 Routine mode

A full-screen card per habit: icon, name, cue ("After I brew coffee"), description. Big **Done** button; **Skip** and **Later** below. Measurable habits show a stepper; habits with a duration show a timer (screen kept awake where possible). Dots at the top show progress. At the end: a summary ("4 of 5 done"), streaks reached, and a celebration.

### 4.3 Habits list

Grouped by routine (or by category, as a toggle). Drag handles to reorder, with arrow buttons as a keyboard alternative. Filters: active · paused · archived. A "+" button opens the template gallery, with "Create my own" at the top.

### 4.4 Habit editor

Sections, with the essentials first:

1. **What:** name, icon, color, category. *(Template already filled in, if one was chosen)*
2. **How much:** Yes/No or Measurable (target, unit, step).
3. **When:** every day · specific days (weekday chips) · N times a week; routine; time (optional); start date.
4. **Reminder:** on/off, minutes before. Warns if it falls in quiet hours.
5. **More** *(folded)*: description, cue, duration, voice aliases, Health rule (iPhone), Google Calendar sync.

A live summary sits at the top: *"Every Mon, Tue, Thu, Fri at 07:00 · Reminder 06:55 · Verified by Health: workouts ≥ 1"*.

### 4.5 Habit detail

Current and best streak, completion rates (7/30/90 days, all time), heatmap, results by weekday, value chart with the target line (measurable), notes, and an editable history list showing the source of each entry. Actions: edit, pause, archive, delete, copy ID (for a direct Siri shortcut).

### 4.6 Statistics

Period selector (7 d · 30 d · 90 d · 12 m · all). Daily-score heatmap, weekly trend, this week vs last week, by routine, by category, best and worst weekdays, "Needs attention" and "Strongest" lists. Every chart has a text summary and a table view.

### 4.7 Weekly review

Week score and change from last week, per-habit results, wins (streaks, perfect days), misses, the week's notes and mood, the reflection field, and suggestions with a one-tap "Apply" (`FR-REV-4`).

### 4.8 Settings

| Section | Contents |
|---|---|
| Profile | Name, language, timezone, day end, week start, theme, edit window |
| Notifications | This device's status and "Enable"; list of devices; default lead time; daily report time; weekly review day and time; quiet hours; routine digests; "Send test" |
| Routines and categories | Add, edit, reorder, delete |
| Integrations | Siri & Shortcuts (tokens, install links, guide) · Apple Health (guide, last sync, delete data) · Google Calendar (connect, status, resync, disconnect) |
| Data | Export JSON / CSV, delete account |

## 5. Onboarding

1. **Welcome:** language preselected from the browser, can be changed.
2. **Sign in:** email (6-digit code) or Google.
3. **Routines:** confirm Morning and Evening times.
4. **First habits:** pick 3–5 templates or create your own. Goal: the first habit exists in under 60 seconds.
5. **Install:** a guide for the detected platform (skipped on desktop if the user wants).
6. **Notifications:** explain what will be sent, then enable it (on iPhone, only after installing). Pick the daily report time.
7. **Extras (optional, any time later):** Siri, Apple Health, Google Calendar. Unfinished items stay in Today's setup checklist.

Steps 5–7 can be skipped.

## 6. Visual design

- **Base:** Tailwind CSS and shadcn/ui with design tokens; light, dark and system themes.
- **Colors:** 8 category colors that pass AA contrast in both themes. Green for done, amber for partial, neutral for pending. Color is never the only signal (icons too).
- **Type:** the system font stack (fast, looks native on each platform).
- **Icons:** lucide for the interface, emoji for habits.
- **Touch:** targets of at least 44 × 44 px. Respect the safe areas of iPhones (notch, home indicator).
- **Motion:** 150–250 ms ease-out; none with "reduce motion". No vibration on iPhone (the browser doesn't support it).

## 7. Accessibility

WCAG 2.2 AA:

- States are shown with icons and text, not color alone.
- Rows have full labels for screen readers: "Meditate, done, 12-day streak".
- The heatmap and charts have text summaries and a table alternative.
- Everything works with a keyboard, including reordering. Focus is always visible.
- Text can grow to 200% without breaking layouts.
- The Undo toast and sync status use `aria-live`.
- Gestures always have a button alternative.

## 8. Tone

Friendly, short and encouraging; never guilt-tripping. Spanish uses *tú*.

| Situation | Español | English |
|---|---|---|
| Missed yesterday | "Ayer no se pudo. Hoy cuenta doble 💪" | "Yesterday didn't happen. Today counts double 💪" |
| Perfect day | "¡Día perfecto! 🎉" | "Perfect day! 🎉" |
| Empty habits list | "Empieza con un hábito pequeño. ¿Qué tal 1 vaso de agua al despertar?" | "Start small. How about a glass of water when you wake up?" |
